# ALII
### Advanced Light Intensity Indicator

This project presents the complete **design, implementation, and operation** of an **Advanced Light Intensity Indicator (ALII)** module.

The system implements four required features using only **discrete analog components, operational amplifiers, comparators, and basic logic gates**, while strictly adhering to the constraint of **no programmable ICs**.

## Key Achievements

- **Noise Filtering:** Successfully filters 50–100 Hz noise using a 2nd-order active low-pass filter.
- **3-bit Flash ADC:** Provides real-time light-level digitization on a 0–7 scale.
- **Stability Detection:** Provides adjustable stability detection from 30–300 seconds.
- **Running Average:** Calculates a running average over an adjustable period of 300–900 seconds.
- **LED Indicators:** All displays are functional with LED indicators for debugging.
